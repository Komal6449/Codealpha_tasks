# 🎵 Music Generation with AI

## 📌 Project Overview

An AI-powered music generation system built using Python, TensorFlow, LSTM Neural Networks, Music21, and Streamlit. The model learns musical patterns from MIDI files and generates new music compositions automatically.

## 🚀 Live Demo

Add your Streamlit app link here:
[Open AI Music Generator](https://codealphatasks-esoz9gefg9osa2krwvlxe8.streamlit.app/)

## 📌 Features

- MIDI file processing
- Music note extraction using Music21
- Deep Learning model using LSTM
- AI-generated music compositions
- Streamlit web interface
- Download generated MIDI music

## 🛠️ Technologies Used

- Python
- TensorFlow
- Keras
- Music21
- NumPy
- Streamlit


## ⚙️ Installation

1. Install Python
2. Install required libraries:
   pip install -r requirements.txt
3. Run the application:
   streamlit run Music_generator.py

## 🧠 Model Workflow

1. Collect MIDI music files.
2. Extract notes and chords using Music21.
3. Preprocess note sequences.
4. Train an LSTM Neural Network.
5. Generate new music sequences.
6. Convert generated notes into MIDI format.
7. Download and play generated music.

## 📊 Dataset

The model was trained on MIDI music files containing piano and classical compositions.

## 🎼 Output

The system generates a MIDI file:
generated_music.mid

which can be played using any MIDI-compatible media player.
